# Состояние новой концепции

Развернут бот с выбором листа, текстом/голосом, AI-категоризацией,
уточнениями, автозаписью и защитой от повторных записей. Архив старой
реализации удалён по запросу пользователя. Код отправлен в main.

Рабочий релиз: 2526362815c1b3a498f42447836ecb4b76b9b21a.
Сервер: 2.26.231.184, контейнер fintracker-sheets-bot-1, перезапусков 0.
Старые api/worker/scheduler/polling остановлены; PostgreSQL и резервные копии сохранены.
Команды Telegram проверены: /start, /sheets, /cancel, /help.

Проверки: 23 Python-сценария, 12 сценариев Google Apps Script, Ruff,
форматирование, mypy strict (21 модуль). GitHub Actions 36085174820 — success.
Проверены живой AI-разбор синтетического расхода и распознавание русского OGG.

Google Apps Script Telegram Expense Bridge опубликован (версия 2), доступ разрешён
пользователем. Серверный env настроен, неверный секрет отклоняется.
Устранена коллизия русских названий: хеширование явно использует UTF-8.
Оба листа читаются (37 и 40 категорий). На временном листе проверены реальные
записи, дробные суммы, сохранение формул и защита от дублей; тестовые данные удалены.
Существующие финансовые записи не изменялись.

Доступны только периоды 10.07–09.08 и 10.08–09.09 2026 года.
Для сегодняшних расходов пользователь должен добавить лист текущего периода.
Работающие листы должны соответствовать описанной в README матрице.

Деплой завершён через deploy/release.sh. Конфигурация запуска находится
в /opt/fintracker/deploy-sheets, исходники — /opt/fintracker/sheets-source.
Серверные секреты и пароль SSH в репозиторий не включены.
