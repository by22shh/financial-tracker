# Расходы в выбранный лист Google Sheets

Решение пользователя от 2026-09-25: прежние бюджеты и остальные функции удаляются.
Остаются подключённая таблица, выбор листа, текст/голос, AI-категоризация и автозапись.

Источник истины — существующая Google-таблица. Категории берутся с выбранного листа.
Новый runtime не запускает прежнюю модель бюджетов, PostgreSQL и планировщик.
Локальный архив прежней реализации удалён по запросу пользователя.

Рабочее допущение: запись в существующую матрицу категория × день с прибавлением суммы.
Вопрос пользователю о формате задан, ответа пока нет. Исходная таблица из предыдущего
проекта предполагается той же; подтверждение ссылки также пока не получено.
