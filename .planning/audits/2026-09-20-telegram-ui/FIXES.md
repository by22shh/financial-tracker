## Дополнительное исправление резервного копирования

Первый запуск обновления безопасно остановился на проверке архива: `tar: security-log: file changed as we read it`. Прежние сервисы восстановлены EXIT-обработчиком; образ и данные ещё не переключались. Причина: одноразовый Compose-контейнер архиватора наследовал healthcheck приложения, который создаёт проверочные файлы. В `deploy/backup.sh` архивирование перенесено в контейнер с read-only томами, отключёнными healthcheck и сетью, без runtime-секретов. Код приложения не менялся; повторная полная сборка не требуется. Синтаксис обоих shell-скриптов проверен.
