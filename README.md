# Финансовый трекер в Telegram

Материалы для проектирования Telegram бота с личными и совместными бюджетами: создание с нуля, вход по коду, расходы текстом/голосом/по чекам, лимиты, общая история и планирование накоплений.

Для разработки с AI: [подробная инструкция разработчику](docs/AI_DEVELOPMENT_GUIDE.md) и [готовый стартовый промпт для интерфейса](docs/AI_START_PROMPT.md). Инструкция задаёт реализацию P0 → P1 → P2, ревью каждого среза и подтверждение требований проверками; реальные внешние блокеры отмечаются отдельно.

- [Архитектура](docs/ARCHITECTURE.md) — 17 принятых решений: стек, модули, транзакции, очередь, GPT-5.6 Luna Medium через OpenAI API, доступ, календарь, развёртывание и восстановление.
- [Контракт данных и команд](docs/DATA_CONTRACT.md) — денежные инварианты, таблицы и ограничения PostgreSQL, индексы, права и карта CMD-01–31.
- [Архитектурное ревью](docs/ARCHITECTURE_REVIEW.md) — устранённые пробелы, 36 дополнительных сценариев испытаний, открытые решения окружения и условия выпуска.
- [Исследование рынка](docs/RESEARCH.md) — 17 продуктов, проверенные источники и обоснование рекомендуемых функций.
- [Критерии приёмки](docs/ACCEPTANCE.md) — проверяемые сценарии, числовые примеры и требования к качеству.

- [Аудит ТЗ](docs/SPEC_REVIEW.md) — недоопределённые правила версии 0.4, приоритетные дополнения и предложенные сценарии проверки.

Версия ТЗ: 0.7, 12 сентября 2026 года. По решению пользователя основная модель — **GPT-5.6 Luna** (`gpt-5.6-luna`) с **reasoning.effort=medium** через **прямой OpenAI Responses API**. Она используется для текста, фото чеков, аналитики и рекомендаций; транскрипция голоса требует отдельной ASR модели. Архитектурная основа P0 и контракты зафиксированы для реализации; совместимость конкретных версий, нагрузка и восстановление проверяются при разработке. Совместный доступ, создание без таблицы, вход по коду, выход и удаление, комментарии и фильтрация по совершившему покупку человеку включены в P0. Пользователь один раз выбирает начало, конец, длительность и правило повторения; далее периоды открываются автоматически. Месячный цикл 10–9 — один из вариантов. Повторяемый шаблон плана позволяет сохранить лимиты без повторной сборки бюджета. Исследованы оба листа предоставленной Google Sheets и их формулы. Владелец подтвердил, что учёт незавершён и часть расходов не внесена. Валюта и страна использования требуют уточнения. Числовые примеры в ТЗ и критериях приёмки вымышлены, если прямо не названы результатами разбора исходной таблицы.

Разработка приложения, подключение бота и изменение внешних таблиц в рамках подготовки этих материалов не выполнялись.
